## Tyk Open Source 

<OssProductListInclude/>

Tyk AI Studio Community Edition is also open source, under the GNU Affero General Public License v3.0 (AGPL 3.0). See [Tyk AI Studio](/ai-management/ai-studio/overview).

Tyk Gateway and Tyk AI Studio also have Enterprise features that need the Enterprise Edition:

| Component | How to get the Enterprise features |
|:---|:---|
| [Tyk Gateway](/tyk-oss-gateway) | Use the `tykio/tyk-gateway-ee` image. The Gateway does not check a license key. |
| [Tyk AI Studio](/ai-management/ai-studio/overview) | Use the Enterprise build and set an AI Studio license key. |

## Closed Source

These Tyk components are proprietary and closed source. Each component needs a license:

| Component | License | Requires |
|:---|:---|:---|
| [Tyk Dashboard](/api-management/dashboard-configuration) | Dashboard license key. Some features also need a claim in the license. | Tyk Gateway |
| [Tyk Developer Portal](/portal/overview/intro) | Separate Developer Portal license key | Tyk Dashboard |
| [Tyk MDCB](/api-management/mdcb) | Separate MDCB license key | Tyk Dashboard |
| [Tyk Operator](/api-management/automations/operator) | Separate Operator license key | Tyk Dashboard |
| [Tyk Sync](/api-management/automations/sync) | Uses the Tyk Dashboard license | Tyk Dashboard |

For the features in each edition and deployment option, see [Tyk Editions, Components and Feature Availability](/apim).
