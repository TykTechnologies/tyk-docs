Get Tyk Open Source Gateway running locally with Docker in a few steps. For other deployment options, see the [installation options](/apim/open-source/installation) page.

## Prerequisites

- [Docker Engine](https://docs.docker.com/engine/install/) 24.0 or later
- [Docker Compose](https://docs.docker.com/compose/install/) v2.20 or later

## Instructions

### Step 1: Create a Gateway configuration file

Create a file named `tyk.conf` with the following content:

```json
{
  "listen_port": 8080,
  "secret": "your-secret",
  "template_path": "/opt/tyk-gateway/templates",
  "app_path": "/opt/tyk-gateway/apps",
  "storage": {
    "type": "redis",
    "host": "tyk-redis",
    "port": 6379
  }
}
```

For a full list of configuration options, see the [Gateway configuration reference](https://tyk.io/docs/tyk-oss-gateway/configuration).

### Step 2: Create a folder for API definitions (Linux only)

The Gateway saves the APIs that you create through the Gateway API in the `apps` folder. The Gateway container runs as user `65532`. On Linux, create the folder and give it to this user before you start the Gateway. If you do not, the Gateway cannot save your APIs:

```bash
mkdir apps
sudo chown 65532:65532 apps
```

On macOS and Windows, skip this step. Docker Desktop creates the folder when the Gateway starts.

### Step 3: Create a Docker Compose file

Create a file named `docker-compose.yml` with the following content:

```yaml
services:
  tyk-gateway:
    image: tykio/tyk-gateway:v5.13.2
    ports:
      - "8080:8080"
    volumes:
      - ./tyk.conf:/opt/tyk-gateway/tyk.conf
      - ./apps:/opt/tyk-gateway/apps
    depends_on:
      - tyk-redis
  tyk-redis:
    image: redis:8.2.0
    ports:
      - "6379:6379"
```

<Note>
`v5.13.2` is the current LTS release. Always check the [Gateway release notes](https://tyk.io/docs/developer-support/release-notes/overview) for the latest stable version before deploying.
</Note>

### Step 4: Start Tyk Gateway

```bash
docker compose up -d
```

## Verify the Installation

Check that the Gateway is running:

```bash
curl localhost:8080/hello
```

Expected response:

```json
{"status":"pass","version":"5.13.2","description":"Tyk GW"}
```
