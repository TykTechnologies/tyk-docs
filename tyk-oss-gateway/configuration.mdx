You can use environment variables to override the config file for the Tyk Gateway. The Gateway configuration file can be found in the `tyk-gateway` folder and by default is called `tyk.conf`, though it can be renamed and specified using the `--conf` flag. Environment variables are created from the dot notation versions of the JSON objects contained with the config files.
To understand how the environment variables notation works, see [Environment Variables](/tyk-oss-gateway/configuration).

All the Gateway environment variables have the prefix `TYK_GW_`. The environment variables will take precedence over the values in the configuration file.

## HTTP Server Options: XFF Depth Configuration and Helm Chart Defaults

### Understanding `xff_depth`
The `http_server_options.xff_depth` setting in `tyk.conf` controls how Tyk Gateway extracts the true client IP address from the `X-Forwarded-For` (XFF) header:

* An `X-Forwarded-For` header contains a comma-separated list of IP addresses representing each proxy hop:
```text
X-Forwarded-For: <client-ip>, <proxy-1>, <proxy-2>
```
* **Counting from the Right:** When `xff_depth` is set to `N`, Tyk counts `N` positions from the **right** (the most recent proxy hop) to identify the trusted client IP.

### Default Value Discrepancies
Be aware of differences in default values across deployment methods:

| Deployment Method | Default `xff_depth` | Extracted IP Behavior |
|---|---|---|
| **Raw Binary / Docker (`tyk.conf`)** | `0` | Extracts the **leftmost** IP address in the header. |
| **Official Tyk Helm Chart** | `1` | Extracts the IP immediately preceding the Kubernetes Ingress controller (`1` hop from the right). |

### Configuring Multi-Tier Proxy Architectures
If your deployment routes traffic through multiple proxy layers (for example, Cloudflare -> AWS ALB -> Kubernetes Ingress -> Tyk Gateway):
* Set `xff_depth: 3` so Tyk steps past the Ingress (`1`), the ALB (`2`), and Cloudflare (`3`) to accurately extract the original client IP.
* Ensure all intermediate proxies are configured as trusted proxies to prevent header spoofing.
