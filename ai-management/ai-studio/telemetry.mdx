## Availability

| Edition   | Deployment Type |
| :------------- | :---------------------- |
| [Community](/ai-management/ai-studio/overview#community-edition) & [Enterprise](/ai-management/ai-studio/overview#enterprise-edition) | Self-Managed |

Tyk AI Studio can send anonymized usage statistics to Tyk to help improve the product and understand how features are being used. From v2.3.0, telemetry is off by default. AI Studio sends nothing until you turn it on.

Telemetry is not for your own monitoring. For metrics, traces, and health endpoints, refer to [Observability](/ai-management/ai-studio/observability).

## What Data is Collected

The telemetry system collects aggregate statistics every hour such as:

- **User counts** by type (admin, developer, chat users)
- **LLM model counts** and token usage
- **Application counts** and proxy usage
- **Chat counts** and interaction statistics
- **team counts**

**No personal data, content, or sensitive information is collected.**

## Privacy & Security

All data is **anonymized** before transmission to ensure user privacy. The system does **not collect any personally identifiable information (PII)**, and **no chat content, prompts, or responses** are ever transmitted. 

Additionally, **API keys and credentials are never included** in telemetry data. To further protect privacy, instance identifiers are **hashed and rotated daily**. All telemetry data is securely transmitted over **HTTPS** to `https://telemetry.tyk.technology`.

## Turn On Telemetry

AI Studio has two telemetry reports. Each report is off by default, and you turn each one on separately.

| Report | Edition | Environment variable | Helm value |
| :--- | :--- | :--- | :--- |
| Anonymized usage statistics, described on this page | Community and Enterprise | [TELEMETRY_ENABLED](/ai-management/ai-studio/ai-studio-env#telemetry_enabled)`=true` | `config.telemetryEnabled: true` |
| License usage reports: usage counts of LLMs, Apps, users, chats, and API interactions, with the license key hashed | Enterprise | [LICENSE_DISABLE_TELEMETRY](/ai-management/ai-studio/ai-studio-env#license_disable_telemetry)`=false` | `config.licenseTelemetryEnabled: true` |

```bash
TELEMETRY_ENABLED=true
LICENSE_DISABLE_TELEMETRY=false   # Enterprise Edition
```

For the Linux packages, set the variables in `/etc/default/tyk-ai-studio` (or `/etc/sysconfig/tyk-ai-studio` on RPM systems). Then restart the `tyk-ai-studio` service.

Before v2.3.0, both reports were on by default. After an upgrade, they are off unless your configuration sets `TELEMETRY_ENABLED=true` or `LICENSE_DISABLE_TELEMETRY=false`.
