The Tyk AI Studio API gives you programmatic access to everything the admin UI manages. This includes LLM providers, Apps, Tools, Data Sources, Catalogs, Teams, Users, Model call settings, Chats, and analytics. Use it to automate setup or to integrate AI Studio with your own tooling.

## Authentication

Every request needs a Bearer token in the `Authorization` header:

```
Authorization: <your-api-key>
```

Generate an API key from your User profile in the admin UI, or with `POST /auth/login` using your AI Studio username and password. The key inherits the permissions of the User it belongs to, so a non-admin key cannot call admin-only endpoints.

```bash
curl -H "Authorization: <your-api-key>" https://<your-ai-studio-host>/llms
```

## Common Endpoints

This is not the full list. Use the endpoint browser in this section for the complete, generated reference.

| Method | Path | Description |
| :--- | :--- | :--- |
| POST | `/auth/login` | Authenticate with a username and password and get a token. |
| GET, POST | `/llms` | List or create LLM provider configurations. |
| GET, POST | `/tools` | List or create Tools. |
| GET, POST | `/datasources` | List or create Data Sources. |
| GET, POST | `/apps` | List or create Apps. |
| GET, POST | `/users` | List or create Users. |
| GET, POST | `/llm-settings` | List or create Model call settings. |
| GET | `/chat-history-records` | List chat history records. |
| GET, POST | `/catalogues` | List or create LLM Catalogs. |
| GET | `/analytics/usage` | Get overall usage analytics. |

All endpoints support pagination, search, and filtering. See each endpoint's schema for its specific query parameters.
