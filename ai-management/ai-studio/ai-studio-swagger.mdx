The Tyk AI Studio API gives you programmatic access to everything the admin UI manages. This includes LLM providers, Apps, Tools, Data Sources, Catalogs, Teams, Users, Workspaces, Model call settings, Chats, and analytics. Use it to automate setup or to integrate AI Studio with your own tooling.

## Authentication

Every request needs a Bearer token in the `Authorization` header:

```
Authorization: Bearer <your-api-key>
```

To get an API key, open **My API key** from your User profile in the admin UI and select **Create key** or **Roll key**.


For automation, use a service account (Enterprise Edition). A service account is a User that signs in with an API key only. {/* TODO: link to workspaces page (service accounts) once merged */}

```bash
curl -H "Authorization: Bearer <your-api-key>" https://<your-ai-studio-host>/llms
```
