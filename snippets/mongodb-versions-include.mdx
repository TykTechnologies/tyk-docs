| Tyk Version       | MongoDB Version  |
| ----------------- | -----------------|
| From 5.X onwards  | MongoDB 7.0.x    |
| From 5.9 onwards  | MongoDB 8.0.x    |

<Note>
Tyk supports MongoDB 5.0.x, 6.0.x, 7.0.x and 8.0 using the `mongo-go` driver, available since Tyk 5.0.2 and the default from Tyk 5.3.0. Prior to Tyk 5.0.2, Tyk used the `mgo` driver, which supported MongoDB 3.x to 4.4.x; these versions are no longer tested since they are EOL, and full compatibility cannot be guaranteed, so upgrading to a supported MongoDB version is recommended. When using Tyk OAS APIs with [Tyk 5.3.0](/developer-support/release-notes/dashboard#TykOAS-v5.3.0) onwards, the minimum supported version of MongoDB is 5.0.

You can also use [Amazon DocumentDB](https://aws.amazon.com/documentdb/) (3.6 and 4 engine) or [Azure Cosmos DB for MongoDB](https://learn.microsoft.com/en-us/azure/cosmos-db/mongodb/introduction) (3.6 and 4 engine) as drop-in replacements for MongoDB.
</Note>
