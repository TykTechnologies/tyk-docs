### Environment Variable Names

Each field in this reference shows its environment variable on the `ENV` line. Use that name. Tyk builds the name from the Go field names in the source code, so it can differ from the JSON key.

To build a name:

1. Start with the prefix of the component.
2. Add the Go field name of each level, in upper case, without underscores.
3. Join the parts with `_`.

| Component | Prefix | JSON key | Environment variable |
|---|---|---|---|
| Tyk Gateway | `TYK_GW` | `analytics_storage.optimisation_max_idle` | `TYK_GW_ANALYTICSSTORAGE_MAXIDLE` |
| Tyk Dashboard | `TYK_DB` | `shared_node_secret` | `TYK_DB_NODESECRET` |
| Tyk Pump | `TYK_PMP` | `analytics_storage_config.host` | `TYK_PMP_ANALYTICSSTORAGECONFIG_HOST` |
| Tyk MDCB | `TYK_MDCB` | `enable_http_profiler` | `TYK_MDCB_HTTPPROFILE` |
| Tyk Identity Broker | `TYK_IB` | `Storage.mongo.mongo_url` | `TYK_IB_STORAGE_MONGOCONF_MONGOURL` |

Environment variables override the configuration file. To ignore the configuration file, set `<PREFIX>_OMITCONFIGFILE` to `true`.
