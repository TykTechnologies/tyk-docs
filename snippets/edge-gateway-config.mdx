### ALLOW_INTERNAL_NETWORK_ACCESS
ENV: <b>ALLOW_INTERNAL_NETWORK_ACCESS</b><br />
Type: `boolean`<br />
Default: `false`<br />

Turns off all internal address checks. Use it for development only. The Edge Gateway logs a warning at startup. Plugins do not get this variable unless you add it to `PLUGIN_ENV_PASSTHROUGH`.

### TYK_AI_LICENSE
ENV: <b>TYK_AI_LICENSE</b><br />
Type: `string`<br />

The license key of an Enterprise Edge Gateway. An Enterprise Edge Gateway with a missing, expired, or invalid license stops before it opens its database. From v2.3.0, the Edge Gateway does not start with a license issued for v2.2 or earlier. A `-migrate` run also needs the license.

### PLUGIN_ENV_PASSTHROUGH
ENV: <b>PLUGIN_ENV_PASSTHROUGH</b><br />
Type: `string`<br />

A comma-separated list of host environment variables to pass to plugins. Plugins get only a built-in list of process, locale, TLS, proxy, and Go runtime variables, plus the variables in this list. An entry that ends in `*` matches a prefix. Available from v2.3.0.

### PLUGIN_GRPC_MAX_MSG_BYTES
ENV: <b>PLUGIN_GRPC_MAX_MSG_BYTES</b><br />
Type: `integer`<br />
Default: `67108864`<br />

The largest message in bytes between the Edge Gateway and its plugins (64 MiB). A plugin that you build with an SDK earlier than v2.3.0 keeps a limit of 4 MiB. Available from v2.3.0.

### DB_LOG_SQL_PARAMS
ENV: <b>DB_LOG_SQL_PARAMS</b><br />
Type: `boolean`<br />
Default: `false`<br />

Adds the values of SQL parameters to SQL log lines. The values can contain credentials, so use this setting for local debugging only. Available from v2.3.0.

### NATIVE_API_*
ENV: <b>NATIVE_API_*</b><br />
Type: `integer` or `duration`<br />

The limits and timings of native API operations, such as Anthropic Message Batches: `NATIVE_API_MAX_BODY_BYTES`, `NATIVE_API_MAX_CONCURRENT_CREATES`, `NATIVE_API_MAX_FILTERED_ITEMS`, `NATIVE_API_MAX_GUARDRAIL_CALLS`, `NATIVE_API_MAX_IN_PROGRESS_PER_APP`, `NATIVE_API_RECONCILE_INTERVAL`, `NATIVE_API_RECONCILE_BATCH`, `NATIVE_API_RECONCILE_WORKERS`, `NATIVE_API_POLL_INTERVAL`, and `NATIVE_API_POLL_MAX_BACKOFF`. The names, defaults, and meanings are the same as on AI Studio. For more information, see the [AI Studio environment variables](/ai-management/ai-studio/ai-studio-env). Available from v2.3.0.

### GUARDRAIL_*
ENV: <b>GUARDRAIL_*</b><br />
Type: `integer`, `duration`, or `string`<br />

The guardrail cache, scan, and shadow settings. The names, defaults, and meanings are the same as on AI Studio. For more information, see the [AI Studio environment variables](/ai-management/ai-studio/ai-studio-env). Enterprise Edition only. Available from v2.3.0.

### GODEBUG
ENV: <b>GODEBUG</b><br />
Type: `string`<br />

Go runtime settings. A FIPS build of the Edge Gateway starts in FIPS 140-3 mode. `GODEBUG=fips140=off` turns off FIPS mode. `GODEBUG=fips140=only` refuses all algorithms that FIPS does not approve, for tests. Refer to [FIPS 140-3 Compliance](/developer-support/release-types/fips-release). Available from v2.3.0.

### AGENT_TRACING_ENABLED
ENV: <b>AGENT_TRACING_ENABLED</b><br />
Type: `boolean`<br />
Default: `false`<br />

Turns on capture for Agent Call Tracing on the Edge Gateway. The Edge Gateway sends the captured events to AI Studio. AI Studio sets all other tracing settings. Refer to [Agent Call Tracing](/ai-management/ai-studio/agent-tracing). Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_QUEUE_MAX_EVENTS
ENV: <b>AGENT_TRACING_QUEUE_MAX_EVENTS</b><br />
Type: `integer`<br />
Default: `10000`<br />

The maximum number of events in the in-memory capture queue. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_QUEUE_MAX_BYTES
ENV: <b>AGENT_TRACING_QUEUE_MAX_BYTES</b><br />
Type: `integer`<br />
Default: `67108864`<br />

The maximum size in bytes of the in-memory capture queue (64 MiB). Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_MAX_STREAM_BUFFER_BYTES
ENV: <b>AGENT_TRACING_MAX_STREAM_BUFFER_BYTES</b><br />
Type: `integer`<br />
Default: `1048576`<br />

The maximum size in bytes of the buffer for one streamed response that tracing captures (1 MiB). Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_FLUSH_INTERVAL
ENV: <b>AGENT_TRACING_FLUSH_INTERVAL</b><br />
Type: `duration`<br />
Default: `10s`<br />

How often the Edge Gateway sends captured events to AI Studio. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_FLUSH_MAX_EVENTS
ENV: <b>AGENT_TRACING_FLUSH_MAX_EVENTS</b><br />
Type: `integer`<br />
Default: `500`<br />

The maximum number of events in one flush. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_CHUNK_MAX_BYTES
ENV: <b>AGENT_TRACING_CHUNK_MAX_BYTES</b><br />
Type: `integer`<br />
Default: `4194304`<br />

The maximum size in bytes of the captured events in one pulse (4 MiB). A value above 8 MiB uses the default. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_KEEP_LIVE_SPAN
ENV: <b>AGENT_TRACING_KEEP_LIVE_SPAN</b><br />
Type: `boolean`<br />
Default: `false`<br />

Keeps the OpenTelemetry span of the Edge Gateway for captured calls while AI Studio exports the assembled spans. Use it when the OpenTelemetry collector of the Edge Gateway is not the export target of AI Studio. With a shared collector, each call appears two times. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_BAGGAGE_ALLOWLIST
ENV: <b>AGENT_TRACING_BAGGAGE_ALLOWLIST</b><br />
Type: `string`<br />
Default: `session.id`<br />

A comma-separated list of the W3C `baggage` keys that the Edge Gateway forwards to LLM and tool upstreams. The Edge Gateway removes all other keys. `none` forwards no baggage. This setting applies in all editions, also when tracing is off. Available from v2.3.0.

### AGENT_TRACING_COMPAT_HEADERS
ENV: <b>AGENT_TRACING_COMPAT_HEADERS</b><br />
Type: `string`<br />
Default: `helicone,portkey,openrouter,bifrost,agent_router,cloudflare,agentcore,mcp_session`<br />

A comma-separated list of the header families of other gateways that tracing reads as declared context. `none` sets an empty list. Enterprise Edition only. Available from v2.3.0.

### AGENT_TRACING_HARNESS_SESSION_HEADERS
ENV: <b>AGENT_TRACING_HARNESS_SESSION_HEADERS</b><br />
Type: `string`<br />
Default: `claude_code,codex_cli,opencode`<br />

A comma-separated list of the coding tools whose session headers tracing reads. Other entries are header names that tracing reads as a session ID. `none` sets an empty list. Enterprise Edition only. Available from v2.3.0.
