Feature availability in Tyk depends on two things:

- **Edition:** Tyk Gateway has an open source Community build and an Enterprise build.
- **Deployment option:** Some features change between Open Source, Self-Managed, Hybrid, and Tyk Cloud deployments.

To select a deployment option, refer to [Deployment Options](/apim).

## Tyk Gateway: Community and Enterprise

Tyk Gateway is open source under the Mozilla Public License 2.0. All Tyk Gateway features are Community features, except the features in this table. The Enterprise features exist only in the Enterprise build (`tykio/tyk-gateway-ee`). The Community build does not check a licence key.

### Enterprise Features on the Community Build

If an API definition uses an Enterprise feature, the Community build still loads the API:

- **Token exchange, upstream OAuth 2.0, upstream Basic Authentication:** Tyk Gateway logs an error and ignores the configuration. Requests go to the upstream without the exchanged token or the upstream credentials.
- **Tyk Streams:** Tyk Gateway logs a warning when it loads the API. It rejects requests to the API with HTTP 403.
- **Cloud secret stores:** Tyk Gateway cannot resolve references to these stores.

## Features by Deployment Option

In a [Hybrid](/tyk-cloud/environments-deployments/hybrid-gateways) deployment, Tyk Cloud runs the Control Plane and you run the Data Plane Gateways. Thus, Control Plane features in Hybrid behave as in Tyk Cloud, and Gateway features behave as in your own deployment.

This table lists only the features that change between deployment options.

| Capability | Open Source | Self-Managed | Hybrid | Tyk Cloud |
| :--- | :--- | :--- | :--- | :--- |
| Enterprise Tyk Gateway features | No | Yes, with the Enterprise build | To be confirmed | To be confirmed |
| [Tyk Gateway configuration](/tyk-oss-gateway/configuration) | Full | Full | Full, for your Data Plane | Managed by Tyk |
| Tyk Gateway version | Any | Any | Same version as the Control Plane | Latest or LTS release channel |
| [Custom plugins](/api-management/plugins/overview) | Local files or bundles | Local files or bundles | Bundles from your server or the Tyk Cloud file server | [Bundles only](/tyk-cloud/using-plugins). Auto-upgrade is not available when plugins are on. |
| [Tyk Pump](/api-management/tyk-pump) | Yes | Yes | Yes, you run it | No. Tyk stores the analytics. |
| [OpenTelemetry export](/tyk-cloud/telemetry) | Yes | Yes | Yes, from your Data Plane | Add-on |
| [Access logs](/api-management/logs/access-logs) | Yes | Yes | Yes | No |
| [Client mTLS to Tyk Gateway](/api-management/implement-tls#secure-hosted-apis-with-mtls) | Yes | Yes | Yes | No |
| [Uptime tests](/planning-for-production/ensure-high-availability/uptime-tests) | To be confirmed | Yes | To be confirmed | No |
| [Custom domains](/tyk-cloud/using-custom-domains) | Not applicable | Not applicable | Not applicable | Yes, without wildcards |
| [Dashboard password policy](/platform-management/dashboard-users) | Not applicable | Yes | No | No |
| [Dashboard audit logs](/api-management/enable-audit-logs-dashboard) | Not applicable | Yes | [Depends on plan](/api-management/cloud/audit-logs) | [Depends on plan](/api-management/cloud/audit-logs) |
| [Tyk Streams](/api-management/event-driven-apis) | No | To be confirmed | To be confirmed | To be confirmed |
| [Tyk AI Studio](/ai-management/ai-studio/overview) | Community Edition | Yes | To be confirmed | No |
