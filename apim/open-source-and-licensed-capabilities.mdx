Tyk has two editions:

- **Community:** Open source software that you can use without a Tyk licence.
- **Enterprise:** Software that needs a Tyk licence. Some Enterprise features are in the Enterprise build of Tyk Gateway. Others are in licensed components, such as Tyk Dashboard.

For deployment options and how to buy a licence, refer to [Deployment Options](/apim).

### Enterprise Features on the Open Source Build

If an API definition uses an Enterprise feature, the open source build still loads the API:

- **Token exchange, upstream OAuth 2.0, upstream Basic Authentication:** Tyk Gateway logs an error and ignores the configuration. Requests go to the upstream without the exchanged token or the upstream credentials.
- **Tyk Streams:** Tyk Gateway logs a warning when it loads the API. It rejects requests to the API with HTTP 403.
- **Cloud secret stores:** Tyk Gateway cannot resolve references to these stores.

## Tyk Dashboard and Multi-Tenancy Features

Tyk Dashboard needs a valid licence for all features. Some features also need the licence to include an extra entitlement.

| Capability | Edition | Licence requirement |
| :--- | :--- | :--- |
| API management, analytics, users, and the classic portal | Enterprise | Tyk Dashboard licence |
| [Single sign-on](/tyk-identity-broker/dashboard-sso) | Enterprise | Tyk Dashboard licence |
| [Audit logs](/api-management/enable-audit-logs-dashboard) (from 5.7.0) | Enterprise | Tyk Dashboard licence |
| [User groups and role-based access control](/platform-management/user-groups) | Enterprise | RBAC entitlement |
| [Multi-organisation users](/api-management/user-management) and API ownership | Enterprise | Multi-team entitlement |
| [Universal Data Graph](/api-management/data-graph#overview) | Enterprise | Universal Data Graph entitlement |
| [GraphQL federation](/api-management/graphql#graphql-federation) | Enterprise | Federation entitlement |
| [Tyk Streams](/api-management/event-driven-apis) management | Enterprise | Streams entitlement |
| [Tyk Governance](/tyk-governance/overview) (from 5.15.0) | Enterprise | Governance entitlement |

The licence also sets the number of Tyk Gateway nodes, and it can set a maximum number of APIs.

## Tyk Developer Portal Features

Tyk Developer Portal needs its own licence and a connection to Tyk Dashboard. A valid licence enables all Tyk Developer Portal features, such as monetization, themes, single sign-on, and dynamic client registration.
