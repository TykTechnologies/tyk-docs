---
title: "Admin User Plan Visibility in Private Catalogues with Audience Restrictions"
description: "In Tyk Enterprise Developer Portal v1.16+, Admin and Provider Admin users cannot view or select plans in private catalogues when audience restrictions are configured, because catalog access is strictly enforced based on consumer team membership."
---

<h2>Overview</h2><p>When an API catalogue in the Enterprise Developer Portal is configured with <strong>Private</strong> visibility and has an <strong>Audience</strong> assigned, access to the catalogue and its associated plans on the Live Portal is strictly restricted to members of the selected consumer teams.</p><h2>Root Cause and Background</h2><p>Starting in Enterprise Developer Portal v1.16.0 and later, catalogue access validation strictly checks the team membership of the logged-in user against the catalogue audience. Because administrative users (such as <strong>Provider Admin</strong> or <strong>Super Admin</strong>) are defined under administrative settings and are not associated with API Consumer teams, they do not match the audience criteria. As a result, administrators cannot view or select plans for these API products when accessing the Live Developer Portal.</p><h2>Workarounds and Best Practices</h2><p>If administrative or internal team members need to view plans or request access to products within audience-restricted private catalogues, consider the following approaches:</p><ul><li><strong>Use a Dedicated Consumer Service Account:</strong> Create an API Consumer user account (for example, a service account) and assign it to the consumer team specified in the catalogue audience. Log into the Live Portal using this account to view plans and manage access requests.</li><li><strong>Remove Audience Restrictions:</strong> If the catalogue only needs to be restricted to authenticated portal users rather than specific teams, remove the audience restrictions while leaving the catalogue visibility as <strong>Private</strong>. When no audience teams are configured, all authenticated users (including administrators) can view the catalogue and its plans.</li><li><strong>Reassign Application Ownership:</strong> When managing applications created by administrator accounts, reassign application ownership to an active API Consumer account in the Admin Portal under <strong>Apps</strong> &gt; <strong>Edit App</strong> &gt; <strong>App owner</strong> before removing user accounts.</li></ul><h2>Applies To</h2><ul><li>Tyk Enterprise Developer Portal v1.16.0 and later</li><li>Private catalogues with configured team audiences</li></ul>
