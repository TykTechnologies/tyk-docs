title: "Admin User Plan Visibility in Private Catalogues with Audience Restrictions"
description: "In Tyk Enterprise Developer Portal v1.16+, Admin and Provider Admin users cannot view or select plans in private catalogues when audience restrictions are configured, because catalog access is strictly enforced based on consumer team membership."
---

## Overview

When an API catalogue in the Enterprise Developer Portal is configured with **Private** visibility and has an **Audience** assigned, access to the catalogue and its associated plans on the Live Portal is strictly restricted to members of the selected consumer teams.

## Root Cause and Background

Starting in Enterprise Developer Portal v1.16.0 and later, catalogue access validation strictly checks the team membership of the logged-in user against the catalogue audience. Because administrative users (such as **Provider Admin** or **Super Admin**) are defined under administrative settings and are not associated with API Consumer teams, they do not match the audience criteria. As a result, administrators cannot view or select plans for these API products when accessing the Live Developer Portal.

## Workarounds and Best Practices

If administrative or internal team members need to view plans or request access to products within audience-restricted private catalogues, consider the following approaches:

- **Use a Dedicated Consumer Service Account:** Create an API Consumer user account (for example, a service account) and assign it to the consumer team specified in the catalogue audience. Log into the Live Portal using this account to view plans and manage access requests.
- **Remove Audience Restrictions:** If the catalogue only needs to be restricted to authenticated portal users rather than specific teams, remove the audience restrictions while leaving the catalogue visibility as **Private**. When no audience teams are configured, all authenticated users (including administrators) can view the catalogue and its plans.
- **Reassign Application Ownership:** When managing applications created by administrator accounts, reassign application ownership to an active API Consumer account in the Admin Portal under **Apps** > **Edit App** > **App owner** before removing user accounts.

## Applies To

- Tyk Enterprise Developer Portal v1.16.0 and later
- Private catalogues with configured team audiences
