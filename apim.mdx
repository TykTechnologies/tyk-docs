Tyk Gateway, Tyk Pump, Tyk Identity Broker and the Tyk Helm charts are open source under the Mozilla Public License 2.0 (MPL 2.0). Tyk AI Studio Community Edition is open source under the GNU Affero General Public License v3.0 (AGPL 3.0). Tyk Dashboard, Tyk Developer Portal, Tyk MDCB, Tyk Operator and Tyk Sync need a license. The Enterprise features of Tyk Gateway are in a separate Enterprise build. This build is in the `tykio/tyk-gateway-ee` image.

This page shows which features each edition and deployment option includes. For prices and plans, see [Tyk pricing](https://tyk.io/pricing/).

## Editions

Tyk has two editions:

- **Community Edition** is free and open source. It includes Tyk Gateway, Tyk Pump, Tyk Identity Broker, the Helm charts and Tyk AI Studio Community Edition. You run it on your own infrastructure. You configure Tyk Gateway with files or with the [Gateway API](/tyk-gateway-api).
- **Enterprise Edition** needs a license from Tyk. It adds the management components, such as Tyk Dashboard and Tyk Developer Portal. It also adds the Enterprise features of Tyk Gateway and Tyk AI Studio. You can run it yourself (Self-Managed) or Tyk can run it for you (Tyk Cloud).

## Components

- **Open source**: the full component is free.
- **Open core**: the core is free and some features need the Enterprise Edition.
- **Licensed**: the full component needs a license.

## Deployment Options

The feature tables on this page use four deployment options:

- **Community**: Tyk Gateway (`tykio/tyk-gateway`) and other open source components on your own infrastructure, with no license. See [Tyk Open Source](/tyk-open-source).
- **Self-Managed**: the Enterprise Edition on your own infrastructure. You install Tyk Dashboard with a license and the `tykio/tyk-gateway-ee` image. See [Install Tyk Self-Managed](/tyk-self-managed/install).
- **Tyk Cloud**: Tyk runs the control plane and the Cloud Data Planes for you. See [Tyk Cloud](/tyk-cloud).
- **Hybrid**: Tyk runs the control plane in Tyk Cloud. You run the gateways on your own infrastructure. See [Hybrid Gateways](/tyk-cloud/environments-deployments/hybrid-gateways).

## Behavior Without a License

If you configure an Enterprise feature without the Enterprise Edition, the component does not stop. It limits the feature as follows:

| Component | Behavior |
|:---|:---|
| Tyk Gateway (`tykio/tyk-gateway`) | The API loads. The Gateway logs an error and ignores the Enterprise configuration, such as upstream OAuth or token exchange. Requests to a Tyk Streams API return `403 Forbidden`. |
| Tyk Dashboard | Without a valid license, the Dashboard API returns `402 Payment Required` and the UI shows the license page. Without a claim, the Dashboard rejects the related change with `403 Forbidden`. For example, it rejects a Tyk Streams API without the `streams` claim. |
| Tyk Developer Portal | Without a valid license, the Developer Portal blocks requests and shows a license error page. |
| Tyk AI Studio Community Edition | Enterprise endpoints, such as SSO and audit trail, return `402 Payment Required` or `403 Forbidden`. |

## Frequently Asked Questions

<AccordionGroup>
<Accordion title="Is Tyk Gateway Free?">
Yes. Tyk Gateway is open source under MPL 2.0. You can use the `tykio/tyk-gateway` image in production with no license. Some features, such as upstream OAuth, token exchange and Tyk Streams, are only in the Enterprise build (`tykio/tyk-gateway-ee`).
</Accordion>

<Accordion title="Is Tyk Dashboard Open Source?">
No. Tyk Dashboard is a licensed component. You can get a trial license from the [Tyk website](https://tyk.io/self-managed-trial).
</Accordion>

<Accordion title="Can I Use the Tyk Developer Portal With the Open Source Gateway Only?">
No. Tyk Developer Portal needs its own license and a connection to Tyk Dashboard.
</Accordion>

<Accordion title="Is the Tyk MCP Gateway Open Source?">
Yes, for MCP proxies to a remote MCP server. A REST API to MCP proxy, upstream OAuth and token exchange need the Enterprise Edition. See [MCP Gateway](/ai-management/mcp-gateway/overview).
</Accordion>

<Accordion title="Is Tyk AI Studio Open Source?">
Yes. Tyk AI Studio Community Edition is open source under the GNU Affero General Public License v3.0 (AGPL 3.0). You can use it in production with no license. If you change the code and let users access the changed version over a network, AGPL 3.0 requires you to make your changes available to those users.

Enterprise features, such as budget enforcement, SSO and the audit trail, need an AI Studio Enterprise license.
</Accordion>
</AccordionGroup>
